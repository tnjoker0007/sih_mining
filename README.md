# sih_mining

Welcome to the **`sih_mining`** repository!

## 🚀 Branching & Workflow

This project uses a modular branching strategy:
- `main`: Main production & integrated codebase.
- `MOD_1`: Module 1 development.
- `MODD_2`: Module 2 development.
- `MOD_3`: Module 3 development.

For detailed developer commands and merging rules, see [`GIT_WORKFLOW.md`](./GIT_WORKFLOW.md).

## ⚙️ CI/CD

Automated testing and validation run on all pushes and PRs via GitHub Actions ([`.github/workflows/ci.yml`](./.github/workflows/ci.yml)).

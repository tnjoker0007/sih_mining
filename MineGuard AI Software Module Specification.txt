Software Module Specification
Project Title
AI-Enabled Low-Cost Real-Time Mine Subsidence Monitoring, Prediction and Early Warning System with Smart Miner Safety Band

1. Project Overview
The system is an integrated IoT, AI, real-time monitoring, GIS visualization, and wearable safety communication platform designed for mine subsidence monitoring and miner safety.
The system receives real-time data from fixed mine sensor nodes and smart miner safety bands. Sensor data is transmitted through LoRa to an ESP32 gateway and then processed by the backend.
The AI/ML engine analyzes sensor trends and classifies mine conditions into:
🟢 SAFE
🟡 WARNING
🔴 CRITICAL
When a dangerous condition is detected, the system automatically sends alerts to:
Miner Safety Bands
Control Room Dashboard
Rescue Team
Administrators
The software must also support SOS alerts, worker monitoring, rescue communication, and digital mine mapping.

2. User Roles

MODULE 3 – AI/ML SUBSIDENCE RISK PREDICTION
Module Name
AI-Based Subsidence Prediction and Risk Analysis Module
Purpose
This module analyzes multi-sensor data and predicts the risk of mine subsidence.

Input Features
The AI model shall process:
Tilt+Tilt Change Rate+Acceleration+Vibration+Relative Displacement+Displacement Rate+Temperature+Humidity+Pressure+Historical Sensor Trends

AI Output
The AI engine shall classify conditions into:
🟢 SAFE
Normal sensor behavior.
Example:
Risk Score: 15%Status: SAFE
🟡 WARNING
Abnormal changes detected.
Example:
Risk Score: 62%Status: WARNING
🔴 CRITICAL
High probability of dangerous subsidence or abnormal ground/structure movement.
Example:
Risk Score: 91%Status: CRITICAL

AI Processing Flow
Raw Sensor Data       │       ▼Data Cleaning       │       ▼Noise Filtering       │       ▼Feature Extraction       │       ▼Trend Analysis       │       ▼AI / ML Model       │       ▼Risk Score       │       ▼SAFE / WARNING / CRITICAL

Required AI Features
The module should support:
Real-time prediction
Historical trend analysis
Anomaly detection
Risk scoring
Prediction history
Model performance monitoring
The first prototype can implement a hybrid approach:
Rule-Based Detection        +Machine Learning Model        =Final Risk Score
This allows the system to function even when limited training data is available.

MODULE 5 – SMART MINER SAFETY BAND AND EMERGENCY COMMUNICATION
Module Name
Wearable Safety, SOS and Emergency Communication Module
Purpose
This module manages communication between Smart Miner Safety Bands, the gateway, control room, and rescue team.

5.1 Smart Band Data
Each band shall transmit:
Band IDMiner IDBattery LevelSignal StrengthMotion StatusFall Detection StatusSOS StatusLast Communication Time

5.2 Fall Detection
The band uses MPU6050 data.
Logic:
Sudden Acceleration        +Abnormal Orientation        +No Movement        │        ▼Possible Fall        │        ▼Wait for User Response        │   ┌────┴────┐   ▼         ▼Response   No Response   │         │ SAFE       SOS ALERT
The miner can cancel the false alarm using a button.

5.3 SOS System
When the miner presses the SOS button:
SOS BUTTON     │     ▼ESP32     │     ▼LoRa Packet     │     ▼Gateway     │     ▼Control Room     │     ├──────────────► Rescue Team     │     └──────────────► Other Relevant Miners
The software shall create an emergency incident automatically.

5.4 Emergency Alert Broadcasting
The system shall send alerts to all miners or selected miners.
Example:
ALERT TYPE: CRITICALMESSAGE:EVACUATE IMMEDIATELYZONE:TUNNEL ASEVERITY:CRITICAL
The band responds with:
Red LED
Vibration
Buzzer
Display message

5.5 Miner-to-Control Room Communication
The first software version should support low-bandwidth messages.
Example:
HELP REQUIRED
I AM SAFE
MOVE TO ZONE B
RESCUE TEAM APPROACHING

5.6 Quick Emergency Buttons
The control dashboard should allow operators to send predefined messages.
Buttons:
[ EVACUATE ][ STAY CALM ][ MOVE TO SAFE ZONE ][ RESCUE TEAM ON THE WAY ][ ACKNOWLEDGE SOS ]

MINEGUARD AI
MODULE 2 – SMART MINER SAFETY BAND AND EMERGENCY COMMUNICATION
1. Module Overview
Project: AI-Enabled Low-Cost Real-Time Mine Subsidence Monitoring, Prediction and Early Warning System with Smart Miner Safety BandModule Name: Smart Miner Safety Band and Emergency CommunicationAssigned To: Team Member 2Purpose: Build the software functions that manage miners and wearable bands, receive band telemetry, process fall/SOS events, and support emergency communication and alert broadcasting.
2. Smart Band Inputs and Outputs
Inputs
MPU6050 movement/orientation data.
SOS push button event.
Optional microphone or voice-command event.
Battery level.
Signal/communication status.
Outputs
Vibration motor command.
Buzzer command.
LED status command.
OLED/display message.
Emergency acknowledgement.
3. Miner Management
Create, edit and view miner records.
Assign Miner ID, employee details, mine and zone.
Assign one smart band to a miner.
Track current miner safety/communication status.
4. Smart Band Management
Register Band ID and LoRa/device ID.
Link band to miner.
Monitor battery, signal strength and last communication time.
Display online/offline status.
5. Fall Detection Workflow
Sudden acceleration+ Abnormal orientation+ Possible inactivity→ Possible Fall→ Ask/allow miner cancellation→ No response within configured time→ Automatic emergency event/SOSThe implementation must allow false-alarm cancellation and event logging.
6. SOS System
Receive manual SOS from the smart band.
Create SOS event with Miner ID, Band ID, zone/last known location and timestamp.
Send event to Module 3 central alert/rescue system.
Record acknowledgement and incident status.

8. Alert Broadcasting
Broadcast to all miners.
Broadcast to a selected zone.
Send to a specific miner.
Send to a specific band.
Support severity: INFO, WARNING and CRITICAL.
Translate received command into band actions such as vibration, buzzer, LED and display message.
